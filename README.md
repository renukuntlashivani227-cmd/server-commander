# The Server Commander

## Project Overview

This project demonstrates the setup and configuration of a Linux web server using Ubuntu and Apache Web Server.

## Objective

The objective of this project is to configure a server environment, establish a secure SSH connection, install a web server, and host a custom webpage.

## Technologies Used

- Ubuntu Linux
- Apache Web Server
- SSH
- VS Code
- HTML
- Git and GitHub

## Implementation

1. Installed Ubuntu using WSL2.
2. Updated the Ubuntu packages.
3. Installed Apache Web Server.
4. Started and verified the Apache service.
5. Created a custom **Welcome to DecodeLabs** webpage.
6. Tested the webpage using `http://localhost`.
7. Installed and configured OpenSSH Server.
8. Connected to the Ubuntu environment using SSH.
9. Verified the server using command-line tools.
10. Uploaded the project webpage to GitHub.

## Webpage

The custom webpage displays:

**Welcome to DecodeLabs**

**The Server Commander**

The webpage confirms that the Apache Web Server was successfully configured.

## Result

The Ubuntu environment successfully runs Apache Web Server, accepts SSH connections, and serves the custom DecodeLabs webpage.

## Note

This implementation uses Ubuntu on WSL2 as a local server environment. It demonstrates the server, SSH, and web-server portions of the project.
